Boord Notes

Training Guide

How to capture, find and act on farm knowledge on your iPhone.

For Andre and his son.

For app version 2.9 · October 2026

1. What Boord Notes is for

Boord Notes is a private notebook for farm knowledge: how a job is done, what an odd piece of equipment does, what you saw in a block and what it needs. Anything worth handing on goes in, so it is all in one place later.

  • Speak or type. Dictate with the microphone on your iPhone keyboard, in Afrikaans or English. The app stores only the text, never any audio.
  • From what you see to what gets done. A note can carry actions - prune, fertilise with LAN, water more, pick. They go on the To do list until someone ticks them off, and the note then records when it was done.
  • Works without signal. A note saves on the phone first and reaches the server by itself once there is signal again.
  • No sign-in. The app opens straight onto the Capture screen. Anyone who can reach it can read, edit and archive notes, so keep the phone in the right hands.

A note holds a title, the notes text, a block (or any other spot), any number of actions, tags and photos. It also records where you were and the weather when you first saved it.

2. Setting up the phone (once)

Install to the Home Screen before you capture anything. Notes written in a Safari tab are stored separately from the installed app and will look as if they have vanished. Install first, then always open the app from its icon.
  1. Make sure the Tailscale app is installed and signed in on the phone.
  2. Open the farm's address in Safari: https://<server>.<tailnet>.ts.net:9443/app/ (ask whoever set up the server for the exact link).
  3. Tap Share (square with an arrow), then Add to Home Screen.
  4. From now on open Notes from its Home Screen icon (Boord crate with a sky-blue leaf).
  5. When asked, allow Location and Camera access.
Both of you use the same link. There is one address and no accounts.

Once, for the farm: add the blocks in Settings → Blocks (section 7). Until then the Block field on a note is a plain text box.

3. Capturing a note

The app looks and works like an iPhone app. The tabs along the bottom are Capture, To do, Dashboard, Entries, Ask AI (only when AI help is switched on) and Settings. The app opens on Capture. It follows the phone's own light or dark setting.

  1. Title. Keep it short, e.g. "Flush on 8b".
  2. Block. Tap it and pick from the farm's blocks, grouped by type (e.g. TMR: 8a, 8b). For anywhere else choose Somewhere else… and type it, e.g. "near the pump station".
  3. Notes. Tap the field, then tap the microphone key next to the space bar and speak. Tap Done to stop, then read it over and fix any mistakes. If AI help is on, AI Tidy up can clean it up for you (section 6).
  4. Actions NEW. What does this note lead to? Tap + Prune, + Fertilise, + Water and so on, then type with what if it matters, e.g. "LAN 100 g/boom". Add as many as needed. Each one goes on the To do list. If it has already been done, tap its circle so it shows a green tick.
  5. Tags. Tap Choose from existing tags and tap each one that fits, or type a new one and tap Add.
  6. Photos. Tap Add Photo and choose Camera, Photo Library or Files. Photos are shrunk on the phone so they send quickly.
  7. Tap Save Note.

Location and weather

The line under Record location says whether a GPS fix is ready ("Location ready" or "No location available"). Saving never waits for it. The Record location switch turns this off if you do not want it.

  • Location works with no signal. Weather does not, and is left blank rather than filled in later.
  • Both are recorded once, when the note is first created. Editing later does not change them.
Tip for dictation in Afrikaans. Add both keyboards in Settings → General → Keyboard → Keyboards. Dictation follows the keyboard that is active, so switch with the globe key.

4. The To do list NEW

The To do tab lists every action still waiting, grouped by block, with the ones that have waited longest at the top. The red number on the tab is how many are open. Tap the rest of a row to open its note.

Open actions by block
Marking one done

When the job is done: tap the circle next to it. A small panel asks What was used, if different - fill it in if the plan changed (e.g. "used MAP instead"), or leave it empty. Tap Mark Done. The action leaves the list and the note now shows it done, with the date.

You can also tick actions off from inside a note. Ticking off works without signal too - it is sent with the next sync, dated when you ticked it.

5. Finding and reviewing notes

Entries

Search by title, notes text or block. Below the search are filter buttons: tag, block, type (every block of that variety) and action. A note with open actions shows "2 to do" on its card.

A block's history. Choose a block and an action together - say 8a and Fertilise - to see every fertilising of 8a. Each note then shows how that action stands: a green tick with the date it was done and anything noted, or "to do".

Opening a note. Tap it. It slides up from the bottom with its block, actions, tags, notes and photos. Tap Done (top right) or the dimmed area above it to close it. Tap the coordinates to open the spot in your map app, handy for walking back to a particular tree.

Dashboard

A quick summary: total notes, notes this week, how many have photos, tags in use, a count per tag, and the latest notes.

6. AI help (optional)

These two buttons appear only once the server has been given an AI key, and they need signal. Without them, everything else works exactly the same.

  • AI Tidy up (under Notes on Capture) adds punctuation and paragraphs to dictated text and suggests a title, tags and actions - "ons gaan die blok meer natlei" becomes + Water. It keeps Afrikaans as Afrikaans and does not add facts. Nothing changes until you tap Use this for the text, or tap a suggested tag or action to add it. Keep mine throws the suggestion away.
  • Ask AI (its own tab) answers questions from the saved notes only, in English or Afrikaans - for example "When did we last fertilise 8a?" - and lists the notes it used.
Always read an AI suggestion before using it. It can still get a word wrong, and it only knows what is in the notes.

7. Settings

Actions NEWThe actions offered on Capture: Spray, Water, Fertilise, Prune, Pick, Scout to start with. Add others (e.g. Mulch) here or straight from a note.

BackupsMake a backup now and download earlier ones (section 9).

"pruning" and "Pruning" count as the same name everywhere, so a tag, action or block cannot be split in two by a capital letter.

8. Working without signal

Every save goes onto the phone first, so it always works. In the background the app then sends notes to the server, and only afterwards their photos. It tries again about every 10 seconds and straight away when signal returns. You do nothing.

  • The block, tag and action lists are kept on the phone, so the pickers work out in the orchard.
  • Actions ticked off without signal are sent with the next sync, dated when you ticked them.
  • A badge such as "2 not yet synced" shows at the top while notes wait. It normally clears on its own.
  • Do not leave unsynced notes for days. If the app sits unused for about a week, iOS can clear its storage and anything not yet synced is lost. After a run of offline notes, open the app somewhere with signal.

9. Backups

The server makes a full backup (notes and photos) every night at 02:00 and keeps the latest 14. It is skipped if the PC is off at that time.

To make one yourself: Settings → Backups → Back Up Now. The button shows "Backing up..." until done. Each backup in the list has a Download link.

MessageMeaning
Backup createdDone. The new backup is at the top of the list.
Backup failed - can't reach the serverCheck Tailscale and that the server is running.
Backup failed on the server (500)The server was reached but the backup failed, most often a full disk. Ask whoever looks after the PC.
Backup timed outIt may still be finishing. Wait a minute and check the list before trying again.
Now and then, copy the latest backup off the server (cloud drive or USB stick). Backups on the same PC do not protect against that PC's disk failing.

10. When something goes wrong

ProblemWhat to do
"Not yet synced" will not clearSwipe the app away in the app switcher and reopen it from its icon. If it persists, check Tailscale is connected and the address loads in Safari.
Block is a plain text box, not a listNo blocks have been set up yet. Add them in Settings → Blocks, with signal.
An action ticked off still shows on the other phoneThe tick reaches the server with the next sync. Open the app with signal on the phone that ticked it.
AI Tidy up or Ask AI is missingThe server has no AI key yet, or the app has not checked since. Both also need signal.
Add Photo does nothing, or Camera failsOpen the app from the Home Screen icon on the https address. As a fallback, take the photo in the normal Camera app and attach it with Photo Library.
No location on a noteOpen from the Home Screen icon. Check Settings → Privacy & Security → Location Services is on and allowed "While Using". Go outdoors and wait a few seconds. The note saves either way.
Location but no weatherNormal when the note was made without signal. Blank means "not known".
Dictation types the wrong languageSwitch keyboard with the globe key, and confirm both keyboards are added.
A note vanished after installing the iconIt was captured in a Safari tab before installing and cannot be moved across. Re-enter it in the installed app.
App looks normal but everything fails (old :8443 icon)Delete the icon, remove the server from Safari → Settings → Advanced → Website Data, then re-add the icon from the :9443 address.

Quick reference

  • Installed to the Home Screen and opened only from the icon
  • Location and Camera allowed
  • Both Afrikaans and English keyboards added
  • The farm's blocks set up in Settings → Blocks
  • Title, block, notes, actions and tags filled in, then Save Note
  • Check the To do tab, and tick jobs off when they are done
  • Opened the app with signal after a batch of offline notes
  • Check that "not yet synced" has cleared
  • Copy a backup off the server every so often
